# План эксперимента с температурой LLM

## Запрос для тестирования
```
Объясни, что такое рекурсия в программировании, и приведи пример 
оригинального использования рекурсии в реальной жизни (не факториал 
и не числа Фибоначчи).
```

## Структура эксперимента

**Параметры:**
- Модель: `glm-5`
- Температуры: `0`, `0.7`, `1.2`
- Запусков на каждую: `3`
- Всего запросов: `9`

## Матрица запусков

| Запуск | Temperature | Цель проверки |
|--------|-------------|---------------|
| 1-3    | 0           | Детерминизм, точность |
| 4-6    | 0.7         | Баланс точность/креативность |
| 7-9    | 1.2         | Креативность, разнообразие |

## Критерии анализа

### 1. Точность (объяснение рекурсии)
- ✅ Корректное определение
- ✅ Верное описание механизма
- ❌ Фактические ошибки
- Шкала: 1-5 баллов

### 2. Креативность (пример из жизни)
- ✅ Оригинальность идеи
- ✅ Релевантность рекурсии
- ❌ Стандартные примеры (факториал, Фибоначчи)
- Шкала: 1-5 баллов

### 3. Разнообразие (между 3 запусками)
- Идентичные ответы → низкое разнообразие
- Разные формулировки, одна идея → среднее
- Разные идеи и подходы → высокое
- Шкала: 1-5 баллов
